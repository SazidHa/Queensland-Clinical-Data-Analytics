# Queensland Clinical Data Analytics

Portfolio projects demonstrating clinical data engineering, quality assessment, analytics and reporting using public Queensland hospital datasets and synthetic patient data.

## Project status

| Project | Status |
| --- | --- |
| [01 — Emergency Department Quarterly Analytics](01-emergency-department/README.md) | In progress: source profiling and Bronze-layer preparation |
| 02 — Elective Surgery Analytics | Planned |
| 03 — Synthetic EHR Analytics | Planned |

## Technology
Microsoft Fabric (Lakehouse, Spark notebooks, Delta), PySpark, Python; SQL, Data Factory and Power BI are planned for later phases.

## Data and ethics
Source: [Queensland Government open data — Emergency departments quarterly data](https://www.data.qld.gov.au/dataset/emergency-departments-quarterly-data). Source files are not included in this repository; download from the publisher and review licence and definitions. The emergency department records used here are public facility-level aggregates, not patient-level medical records. This is an independent portfolio demonstration, not an official Queensland Health product.
